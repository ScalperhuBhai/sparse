# SPARSE v0.1.0

First public source release of the SPARSE CPU-based event-camera research pipeline.

- Run a seeded synthetic recording from the command line and inspect the output in an offline viewer.
- Evaluate the same pipeline on EBSSA telescope recordings and export detections, tracks, latency, and accuracy metrics.
- Follow the benchmark guide for reference measurements, result limitations, and instructions for independent evaluation.

Start with the repository README and use BENCHMARKS.md for comparison runs.
